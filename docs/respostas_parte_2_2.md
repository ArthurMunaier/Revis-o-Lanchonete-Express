# Respostas — Conceitos Flutter

**1. Scaffold**  
Cria a estrutura básica de uma tela Flutter, como AppBar e body.

**2. AppBar**  
Mostra uma barra no topo da tela, geralmente com o título.

**3. StatelessWidget e StatefulWidget**  
StatelessWidget não possui estado que muda. StatefulWidget pode alterar seus dados e atualizar a tela.

**4. setState**  
Atualiza a interface quando algum valor do StatefulWidget muda.

**5. Navigator.push**  
Usamos para abrir uma nova tela.

**6. Navigator.pop**  
Usamos para voltar e fechar a tela atual.

**7. TextEditingController**  
Controla o texto de um TextField e permite acessar ou limpar o que foi digitado.

**8. Validação**  
Impede que o usuário envie um pedido sem preencher os campos obrigatórios.

**9. SnackBar**  
Exibe uma mensagem rápida para o usuário.

**10. showModalBottomSheet**  
Abre um painel na parte inferior da tela.

**11. AnimatedContainer**  
Faz uma transição animada quando as propriedades do Container são alteradas.

**12. SingleChildScrollView**  
Permite rolar o conteúdo e ajuda a evitar overflow.

**13. CardProduto**  
É um widget reutilizável que evita repetir o código de cada produto.

**14. Column e ListView**  
Column coloca widgets um abaixo do outro. ListView faz uma lista que pode ser rolada.

**15. Separação em widgets**  
Ajuda a deixar o projeto mais organizado e facilita a manutenção do código.
