# Respostas — Parte 2

1. **Scaffold:** É a estrutura principal de uma tela. Ele organiza partes como AppBar, body e outros elementos.

2. **AppBar:** É a barra superior da tela, normalmente usada para colocar o título e ações.

3. **StatelessWidget x StatefulWidget:** StatelessWidget não muda seu estado. StatefulWidget pode mudar informações na tela durante a execução.

4. **setState:** Serve para avisar ao Flutter que algum dado mudou e que a tela precisa ser atualizada.

5. **Navigator.push:** Abre uma nova tela por cima da tela atual.

6. **Navigator.pop:** Fecha a tela atual e volta para a tela anterior.

7. **TextEditingController:** Permite pegar, alterar e limpar o texto digitado em um TextField.

8. **Validação:** É importante para evitar o envio de dados obrigatórios vazios ou incorretos.

9. **SnackBar:** Mostra uma mensagem rápida na parte de baixo da tela.

10. **showModalBottomSheet:** Abre uma pequena janela na parte inferior da tela, normalmente para mostrar informações ou opções.

11. **AnimatedContainer:** Permite fazer animações quando propriedades do Container mudam, como tamanho, cor e borda.

12. **SingleChildScrollView:** Permite rolar a tela quando o conteúdo é maior que o espaço disponível.

13. **CardProduto:** Evita repetir código e facilita a criação de vários produtos com o mesmo visual.

14. **Column x ListView:** Column organiza widgets em uma coluna, mas não possui rolagem própria. ListView organiza itens em lista e permite rolagem.

15. **Separar em widgets:** Deixa o código mais organizado, fácil de entender, reutilizar e modificar.
